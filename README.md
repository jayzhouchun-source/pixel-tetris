# PIXEL TETRIS · 像素街机俄罗斯方块

一个单文件、零依赖的复古街机风俄罗斯方块。纯 HTML + CSS + 原生 JavaScript，方块、光效、音效与音乐全部由代码实时生成，可完全离线运行。

## 在线试玩

> GitHub Pages 地址部署完成后会补充在这里。

## 玩法

完整现代俄罗斯方块规则：

- 7-bag 随机、SRS 旋转与踢墙
- Hold 暂存（每个方块一次）
- Ghost 落点预览、Next 队列
- 软降 / 硬降、锁定延迟与重置
- 消行计分、连击加成、每 10 行升级加速
- 本地最高分排行榜（localStorage）

## 操作

| 按键 | 功能 |
| --- | --- |
| ← / → | 左右移动（按住连发） |
| ↓ | 软降 |
| Space | 硬降 |
| ↑ / X | 顺时针旋转 |
| Z / Ctrl | 逆时针旋转 |
| C / Shift | Hold |
| P / Esc | 暂停 |
| M | 静音 |
| Enter | 开始 / 重新开始 |

手机端会自动显示触屏按键：方向、旋转、软降、硬降、Hold、暂停。

## 本地运行

直接双击 `index.html`，或用任意静态服务器打开即可，无需安装依赖、无需联网。

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 技术要点

- Canvas 渲染 + CRT 扫描线 / 霓虹光晕 / 粒子 / 屏幕震动
- Web Audio API 合成音效与芯片音乐，带前瞻调度
- 固定时间步长（60Hz）游戏循环，DPR 自适应
- 响应式布局与触屏手势，桌面 / 手机均可玩
